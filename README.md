Instagram Follower Tracker
Una aplicación web moderna y minimalista diseñada para el monitoreo de métricas de audiencia en Instagram. Este proyecto permite a los usuarios gestionar su comunidad mediante la detección de cambios en sus listas de seguidores, priorizando la seguridad y una experiencia de usuario fluida.

Características
Detección de Unfollowers: Rastreo preciso de las cuentas que han dejado de seguirte.

Interfaz Glassmorphism: Diseño contemporáneo basado en transparencias, desenfoques y una estética limpia.

Dashboard Estadístico: Visualización clara de los datos y la evolución de tu cuenta.

Diseño Responsive: Optimizado para su visualización en dispositivos móviles y de escritorio.

Seguridad: Módulo de autenticación para la protección de sesiones de usuario.

Tecnologías Utilizadas
Frontend: HTML5, CSS3 (con enfoque en diseño visual avanzado) y lógica de componentes.

Backend: Lógica de servidor para la comparación de datos y gestión de estados.

Base de Datos: Almacenamiento cronológico para el seguimiento de listas de seguidores.

Diseño: Estilo minimalista con efectos de desenfoque y animaciones sutiles.




Para clonar y ejecutar este proyecto localmente, sigue estos pasos:

1. Clonar el repositorio:

Bash
"git clone https://github.com/tu-usuario/instagram-follower-tracker.git

2. Navegar al directorio del proyecto:

Bash
cd instagram-follower-tracker

3. Configurar las variables de entorno:
Crea un archivo .env en la raíz y configura tus credenciales de base de datos y claves de API necesarias.

4. Ejecutar la aplicación:
(Dependiendo de tu entorno de ejecución, por ejemplo:)

Bash
npm install
npm start
